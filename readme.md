# Project Structure and Data Description

This repository contains datasets, processing scripts, models, and outputs for historical map georeferencing, displacement estimation, instance extraction, and change profiling.

## Environment Setup

Users can set up the required environment using either `environment.yml` (for Conda) or `requirements.txt` (for pip).

**Using Conda:**
```bash
conda env create -f environment.yml
conda activate 
```

**Using pip:**
```bash
pip install -r requirements.txt
```

## 1. data

This folder contains data example data used throughout the pipeline.

### maps, gcps, masks
Samples of original historical maps, ground control points (GCPs), and district masks used to crop the exact spatial extent of interest.

### vector_annotations
Examples of maps with manually vectorized shapefiles (.shp). These can be visualized in GIS software such as QGIS.

### instance_extraction
Training samples for instance extraction. Each sample consists of a map sequence and the corresponding ground truth for the target year only.

### displacement_estimation
Samples used for training and testing displacement estimation models. 

### building_blocks
Examples of derived building blocks used for spatial aggregation and change analysis.

### aligned_instances
Examples of extracted instances aligned using predicted displacement fields.
- Stored as .npy files containing instance IDs
- Corresponding .png visualization files are provided, where different gray values indicate different instance IDs

## 2. output

This folder will be created to store outputs generated by different stages of the pipeline.

### georeferenced
Results of georeferenced and rectified map sheets.

Georeferenced maps are organized by year (e.g., 1878), with each folder containing:
- georeferenced maps
- district masks
- cropped maps based on the district masks

Rectified maps are organized by district (e.g., 0006)

### displacement_training
Cropped training pairs (Img_src, Img_tar), foreground objects, and text masks used to synthesize training data for displacement estimation.
Each training paris will form a triplet with synthesized object changes and text displacement.

### displacement_inference
Inference results from the pretrained displacement estimation model, including:
- **inf_predictions**: small inference samples. An image consists of original map patches, their overlay, and overlay of aligned patches.
- **inf_displacement**: visualization of the estimated displacement fields
- **inf_img**: visualization of original images and warped images using the estimated displacement

### instance_inference
Inference results for instance extraction using the pretrained model.
- Instances are stored by ID in .npy format
- Visualizations are provided in .png format

### derived_changes
Examples of change detection results derived from IoU scores computed from aligned instances.
IoU values are binarized to indicate change vs. no-change.

### building_blocks_output
Examples of building blocks aggregating average IoU values to approximate changes within each block.
- Color-mapped raster outputs. The lower the IoU, the higher the change intensity.
- Vectorized results in GeoJSON format

## 3. code
### 3.1 data_processing

This folder contains scripts for data preprocessing, georeferencing, rectification, and patch-wise cropping.

#### georeference_maps.py
Converts map images (.jpg) into georeferenced GeoTIFFs (.tiff) using GCPs (.json).
District masks (.gpkg) are used to crop maps to specific districts.
Outputs are organized by year (e.g., 1878) under:
```
output/georeferenced/
```

#### rectify_maps.py
Rectifies maps of the same district from different years into a common image plane (same coordinate system and size).
The 1878 map is used as the reference, and other maps are transformed accordingly.
Outputs are organized by district (e.g., 006) under:
```
output/georeferenced/rectified/
```

#### crop_foreground_objects.py
Randomly crops foreground objects (up to 5 per sample) along with their masks to simulate object changes for displacement estimation.
Outputs are saved in:
```
output/displacement_training/Foreground_img
output/displacement_training/Foreground_mask
```

#### crop_maps_for_training.py
Crops pairs of maps from successive editions of the same district at identical spatial locations using district masks.
Produces paired map patches with matching indices in:
```
output/displacement_training/Img_src
output/displacement_training/Img_tar
```

### 3.2. displacement_estimation

This module contains code and resources for estimating spatial displacement between maps.

#### data
Data loaders and utilities, including synthesis of training triplets using foreground change masks, text masks, and map tiling.

#### model
Model definitions for displacement estimation, including GluNet and WarpC-GluNet.
The architecture follows WarpC-GluNet.

#### results
Saved checkpoints and visualization outputs for training and validation.

#### train.py
Train the displacement estimation model:
```bash
python train.py
```

#### test.py
Run test using the pretrained model:
```bash
python test.py \
  --path ../../output/displacement_inference \
  --model ../../pretrained_weights/displacement_estimation/best_weight.pth \
  --year_sc 1900 \
  --year_tar 1937 \
  --cuda
```

#### losses.py
Loss functions, including triplet consistency loss.

#### log.py
Logging utilities.

#### plot.py
Visualization and plotting utilities.

### 3.3. instance_extraction

This module focuses on multi-temporal instance segmentation.

#### data
Data loaders for single images and image sequences.

#### pretrained
Pretrained instance extraction weights (best_model.pth) and example prediction outputs.

#### .utils
Utility functions to reconstruct full maps from patch-wise predictions.

#### model.py
Instance extraction model architecture with multi-temporal feature fusion.

#### train_instance_fuse.py
Train instance segmentation with multi-temporal feature fusion.

#### test_instance_fuse.py
Test instance segmentation with multi-temporal feature fusion. 
This produces small testing checkpoint samples.

#### infer_instance_fuse.py
Infer instance segmentation with multi-temporal feature fusion.
The script predicts instances for the entire dataset (data_samples/instance_extraction) and stitches patch-level predictions into a complete map.


### 3.4. change_profiling

This module derives and profiles spatial changes based on aligned instances.

#### warp_instance.py
Warps extracted instances using estimated displacement fields to align instances across different years.

#### derive_changes.py
Computes Intersection over Union (IoU) between aligned instances from different years to derive change maps.
Example outputs are stored in:
```
output/derived_changes/
```

#### merge_building_blocks
Merge extracted building instances into building blocks, divided by roads

#### coco_pano_ext_demo_new
Utilities for IoU computation.

#### building_blocks_iou_and_vectorization.py
Aggregates IoU values per building block and vectorizes the results.
Example outputs are stored in:
```
output/building_blocks_output/
```
